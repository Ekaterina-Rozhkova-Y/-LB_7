## Вариант 22

## Условие задачи
Составить программу, которая интерпретирует степени 10 в соответствующие приставки вида «пико», «нано» ... «тера» (Вариант 22). Программа должна корректно обрабатывать ввод и выводить приставку для степеней от -24 до -1, а также сообщать об ошибке, если ввод некорректен или степень выходит за допустимые пределы.

## 1. Алгоритм и блок-схема

### Алгоритм

1. Начало.
2. Запросить у пользователя степень числа 10 (`p`).
3. Проверить корректность ввода (если введено не число — вывести ошибку и завершить программу).
4. Вывести на экран слово "Приставка: ".
5. В зависимости от значения `p` (с помощью `switch-case`) вывести соответствующую отрицательную приставку:
    * `-24` → иокто (y)
    * `-21` → зепто (z)
    * `-18` → атто (a)
    * `-15` → фемто (f)
    * `-12` → пико (p)
    * `-9` → нано (n)
    * `-6` → микро (мк)
    * `-3` → милли (м)
    * `-2` → санти (с)
    * `-1` → деци (д)
6. Если значение `p` не совпало ни с одним из перечисленных (включая 0 и положительные числа), вывести сообщение: "для степени 10^[p] приставка не предусмотрена".
7. Конец.

## 3. Код программы

int DZ() {

    setlocale(LC_CTYPE, "RUS");

    int p;

    printf("Введите степень числа 10 (от -24 до 24): ");
    if (scanf("%d", &p) != 1) {
        printf("Ошибка: неверный формат ввода.\n");
        return 1;
    }

    printf("Приставка: ");

    switch (p) {
    case -24: printf("иокто (y)\n"); break;
    case -21: printf("зепто (z)\n"); break;
    case -18: printf("атто (a)\n"); break;
    case -15: printf("фемто (f)\n"); break;
    case -12: printf("пико (p)\n"); break;
    case -9:  printf("нано (n)\n"); break;
    case -6:  printf("микро (мк)\n"); break;
    case -3:  printf("милли (м)\n"); break;
    case -2:  printf("санти (с)\n"); break;
    case -1:  printf("деци (д)\n"); break;


    default:
        printf("для степени 10^%d приставка не предусмотрена\n", p);
        break;
    }

    return 0;
}

int main() {

    DZ();
    
    return 0;
    
}
